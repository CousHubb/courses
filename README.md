# Courses

Liste de courses : scanne le code-barres d'un emballage, le produit s'ajoute à ta liste avec son nom, sa photo et son rayon.

## Télécharger

- **Android** : [Courses.apk](https://github.com/CousHubb/courses/releases/latest/download/Courses.apk), la dernière version
- **iPhone ou navigateur** : [coushubb.github.io/courses](https://coushubb.github.io/courses/), puis « Sur l'écran d'accueil » (Safari) ou « Installer l'application » (Chrome)

Toutes les versions et ce qui a changé : [Releases](https://github.com/CousHubb/courses/releases).

## Installer l'APK

1. Ouvre le lien Courses.apk sur le téléphone.
2. Si Android le demande, autorise le navigateur à installer des applis.
3. Si Play Protect avertit d'un développeur inconnu, choisis « Installer quand même ».

Pour mettre à jour, installe la nouvelle APK par-dessus l'ancienne : ta liste est conservée.

---

Ce dépôt ne contient que l'app prête à l'emploi. Les produits viennent d'[Open Food Facts](https://world.openfoodfacts.org) ; le lecteur de codes-barres utilise [ZXing](https://github.com/zxing-cpp/zxing-cpp) (licences dans `vendor/`).
